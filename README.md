How Many Tabs Do You Have Open? — one number, digits only: the honest count of browser tabs open at that moment. This entry answers 113: a real, lived-in count, high enough to surprise and specific enough to read as counted rather than chosen, hinting at a researcher with several windows of sources open at once.

## Run it

```sh
node main.ts
```

It writes the count to `/output/entry.txt`.
